# 02｜UI / UX 规格

## 1. 设计原则

1. **运营优先**：高频信息和操作可在一屏完成，避免过度留白。
2. **状态透明**：真实/演示、已同步/过期、已配置/有效状态、成功/部分失败必须可辨认。
3. **渐进复杂度**：默认显示常用字段，高级设置按需展开。
4. **可撤回优先**：优先暂停、保存草稿、复制；危险操作单独确认。
5. **数据先于装饰**：不使用大面积渐变、玻璃拟态、背景插画或无意义动效。
6. **不依赖颜色**：状态同时使用文字、图标和颜色。

## 2. 设计基线

- 桌面设计画布：1440 × 900。
- 最小完整编辑宽度：1180px。
- 1024–1179px：折叠侧栏，表格允许横向滚动。
- 小于 1024px：保留总览和只读详情，隐藏批量编辑与创建向导入口，并提示使用桌面端。
- 4px spacing grid。
- 页面内容最大宽度不固定，数据表格应使用可用宽度。
- 侧栏宽 232px，折叠后 64px。
- 顶栏高 60px；表格工具栏高 52px；标准控件高 36px；紧凑控件高 32px。

设计变量以 `design/tokens.json` 为准。

## 3. 全局框架

```text
┌───────────────┬─────────────────────────────────────────────────────────┐
│ 品牌 / 组织    │ 账户选择  日期范围  对比  刷新/同步  帮助  用户          │
├───────────────┼─────────────────────────────────────────────────────────┤
│ 总览           │ 页面标题 / 面包屑 / 页面级操作                           │
│ 广告管理       │                                                         │
│ 素材中心       │ 主要内容                                                │
│ 自定义报表     │                                                         │
│ 同步与错误     │                                                         │
│ 设置           │                                                         │
└───────────────┴─────────────────────────────────────────────────────────┘
```

### 左侧导航

固定顺序：

1. 总览
2. 广告管理
3. 素材中心
4. 自定义报表
5. 同步与错误
6. 设置

底部显示：

- 当前连接类型：真实 / 演示。
- Meta 连接健康状态。
- 最近同步时间。

### 顶栏

从左到右：

- 广告账户选择器：名称、`act_...` 后四位、币种、时区、状态。
- 日期范围：今天、昨天、近 7 天、近 14 天、近 30 天、本月、上月、自定义。
- 对比开关：上一周期或去年同期。
- 手动刷新：点击后进入队列，显示任务进度，不阻塞页面。
- 全局帮助与用户菜单。

当选择多个账户且币种不一致时，顶栏显示警告，KPI 按币种分组，不做虚假总额。

## 4. 页面规格

## 4.1 登录 `/login`

布局：居中 420px 表单卡片，不做营销首页。

内容：

- 产品名称和“非 Meta 官方产品”说明。
- 邮箱、密码、登录。
- 忘记密码。
- 开发环境可显示“使用演示管理员”按钮；生产默认隐藏。
- 错误消息紧贴字段，不仅使用 Toast。

## 4.2 Meta 接入 `/onboarding/meta`

四段式：

1. 说明将请求的权限和用途。
2. “连接 Meta”主按钮；“使用演示账户”次按钮。
3. OAuth 返回后列出可访问账户，支持搜索与多选。
4. 显示首次同步进度和可进入工作台按钮。

权限卡必须分别说明：

- `ads_read`：读取广告结构和报表。
- `ads_management`：创建/修改广告，仅在启用写入时申请。
- `business_management`：只有资产发现确实需要时才申请。

## 4.3 总览 `/overview`

### 第一行：上下文与状态

- 页面标题“广告总览”。
- 数据新鲜度：对象更新、报表更新、账户时区。
- 演示模式时显示持续可见的黄色标签“演示数据，不会写入 Meta”。

### 第二行：KPI 卡

默认 8 个，可横向压缩为两行：

- 花费
- 购买金额/转化价值
- ROAS
- 转化量
- CPA
- 曝光
- CTR
- CPC

每张卡包含：

- 当前值。
- 对比变化百分比。
- 变化方向图标。
- 指标定义 tooltip。
- 数据缺失时显示 `—`，不能显示 0 冒充缺失。

### 第三行

左侧 8/12：趋势图。默认双轴“花费 / 转化价值”，可切换指标。  
右侧 4/12：账户健康面板：

- Token 到期。
- 同步失败。
- 账户状态。
- 活跃广告数。
- 未解决错误数。

### 第四行

- Top Campaign 表格：花费、结果、CPA、ROAS、状态。
- 异常关注：高花费无转化、频次过高、CTR 显著下降。MVP 只做规则化提示，不声称 AI 诊断。

## 4.4 广告管理 `/campaigns`

这是核心页面。

### 顶部层级切换

使用 Segmented Control：

- 广告系列 Campaign
- 广告组 Ad Set
- 广告 Ad

URL 保持 `?level=campaign|adset|ad`，刷新不丢状态。

### 工具栏

第一排：

- 搜索：名称或 Meta ID。
- 筛选器按钮，显示已启用数量。
- 状态快捷筛选。
- “保存视图”。
- “列”。
- “导出”。
- 右侧“新建广告”。

第二排仅在有筛选条件时出现筛选 chip，例如：

```text
有效状态 = ACTIVE ×   花费 > ₩100,000 ×   ROAS < 1.5 ×   清除全部
```

### 表格

固定列顺序：

1. 选择框
2. 开关 / configured status
3. 名称
4. 投放状态 / effective status
5. 预算
6. 花费
7. 结果
8. 每次结果成本
9. 转化价值
10. ROAS
11. 曝光
12. CTR
13. CPC
14. 更新时间
15. 更多操作

规则：

- 表头 sticky。
- 名称列 sticky，宽 260–360px。
- 数字右对齐，统一千位分隔和小数位。
- 支持列宽调整、显示隐藏；保存到 Saved View。
- 行点击打开右侧抽屉；复选框点击不打开。
- 状态开关不立即提交：先出现确认 Popover，说明对象数和影响。
- 行处于同步/修改中时显示进度图标，禁止重复提交。
- effective status 使用图标和文字，例如“未投放：广告组已暂停”。
- 加载使用 skeleton row；空状态给出清除筛选或新建按钮。

### 批量操作栏

选中对象后固定在表格上方：

```text
已选择 12 项 | 启用 | 暂停 | 修改预算 | 复制 | 更多 | 取消选择
```

- 若跨层级或不支持操作，按钮禁用并解释。
- 预算修改支持“设为固定值”和“按百分比调整”；MVP 可先实现固定值。
- 提交前显示确认 Dialog，列出对象数量、账户、币种和失败不会自动回滚。

### 详情抽屉

宽 480px，可扩展至 720px。

Tabs：

- 概览：状态、预算、排期、最近 7 天指标。
- 设置：对象配置，按组显示。
- 趋势：迷你图表和日表。
- 活动：本系统审计日志；Meta 活动如接入则单独标识。

底部固定按钮：编辑、复制、更多。只读用户不显示写入按钮。

## 4.5 新建广告 `/campaigns/new`

全屏页面，顶部显示步骤与草稿状态。

### Step 1：Campaign

字段：

- 名称（必填）。
- 购买类型（默认 Auction；只展示 API/账户支持项）。
- 广告目标（从版本化 allowlist）。
- 特殊广告类别。
- Campaign 预算模式。
- 状态：默认 PAUSED。

### Step 2：Ad Set

分区：

- 转化：转化位置、优化事件、Pixel / 数据集、推广对象。
- 预算与排期：预算、开始/结束、账户时区。
- 受众：地区、年龄、性别、详细定向；高级配置折叠。
- 版位：Advantage+ 或手动；仅显示支持组合。
- 优化与投放：optimization goal、billing event、bid strategy、attribution。

右侧固定显示“受众摘要 / 预计覆盖”。只有接口可用时才显示真实 estimate，否则标注“暂不可用”。

### Step 3：Creative / Ad

- 身份：Facebook Page、Instagram Account。
- 格式：单图/视频、轮播；MVP 至少完整支持单图/视频。
- 素材选择或上传。
- 主文案、标题、描述、网站 URL、CTA、URL 参数。
- 版位预览切换。

### Step 4：审核与发布

按对象分组展示：

- Campaign 设置。
- Ad Set 设置。
- Ad/Creative 设置。
- 权限与连接检查。
- 警告与阻塞错误。
- 预计创建 3 个对象，默认状态 PAUSED。

底部操作：

- 返回修改。
- 保存草稿。
- 发布到 Meta（受四层写入守卫控制）。

发布结果页按对象显示成功/失败、Meta ID、错误原因和下一步，不使用单一“发布失败”吞掉细节。

## 4.6 素材中心 `/creatives`

- 网格 / 表格切换。
- 图片、视频、Creative 三个 tab。
- 搜索、类型、尺寸、创建时间、使用状态筛选。
- 卡片显示缩略图、名称、尺寸/时长、最近使用、关联广告数。
- 详情抽屉显示元数据、关联广告、预览和复制引用。
- 上传采用显式进度和失败重试；视频处理状态需要轮询。

## 4.7 自定义报表 `/reports`

三栏布局：

- 左：查询配置，宽 300px。
- 中：图表和表格。
- 右侧可选：字段目录 / 预设，宽 300px。

查询配置：

- 层级。
- 日期和 time increment。
- 指标多选。
- Breakdown 多选，实时校验组合。
- 过滤条件。
- 归因窗口。

查询按钮旁显示预计规模：小 / 中 / 大。大查询创建后台任务。

结果区：

- 运行中显示阶段：排队、Meta 生成、下载、入库、完成。
- 可切换表格、趋势图。
- 保存预设、复制预设、导出 CSV。
- 表格底部合计必须说明 Meta 汇总值或系统计算值。

## 4.8 同步与错误 `/sync-center`

Tabs：

- 同步任务
- API 错误
- 数据新鲜度
- 审计日志

同步任务列：类型、账户、范围、状态、进度、开始/结束、重试次数、错误、requestId。

错误详情：

- 人类可读标题。
- 发生位置和影响。
- 是否可重试。
- Meta code/subcode 与 fbtrace_id（不显示 token）。
- 建议修复动作。

## 4.9 设置

### 连接 `/settings/connections`

每个连接卡：

- Meta 用户/业务标识。
- 已授权 scopes。
- Token 状态与到期时间。
- 关联账户数。
- 最近验证。
- 重新授权、断开。

断开连接前说明：停止同步，但保留已同步数据；是否删除历史数据应为独立高风险动作。

### 成员 `/settings/members`

- 成员、邮箱、角色、状态、最后登录。
- Owner 才能管理角色。
- 不能移除最后一位 Owner。

## 5. 组件状态规范

每个数据组件必须具备：

- Initial loading。
- Refreshing（保留旧数据）。
- Empty。
- Filtered empty。
- Partial data。
- Stale data。
- Permission denied。
- Connection expired。
- Recoverable error。
- Fatal configuration error。

Toast 只用于短期确认；需要用户采取行动的错误必须留在页面中。

## 6. 视觉规范

- 字体：系统无衬线；中文优先 `Inter, "PingFang SC", "Microsoft YaHei", sans-serif`。
- 页面背景：浅中性灰；内容卡白色。
- 主色用于主要操作和选中态，不大面积铺满。
- 成功、警告、错误颜色均配合图标与文字。
- 圆角：控件 8px；卡片 10px；大 Dialog 12px。
- 阴影克制，优先边框区分层级。
- 表格正文 13px；页面正文 14px；标题 20–24px。

## 7. 可访问性与键盘

- 所有控件有可访问名称。
- Tab 顺序与视觉顺序一致。
- `Esc` 关闭 Popover/Drawer/Dialog；关闭前保存草稿状态。
- 表格行选择可键盘操作。
- 焦点样式清楚且不被 outline reset。
- 图表提供文本摘要或可访问数据表。
- 颜色对比达到 WCAG 2.2 AA。
- 状态不只用红绿区分。

## 8. 文案规则

- 直接说结果和下一步。
- 不把 Meta API 错误原文整段丢给用户。
- 示例：
  - 不好：“Error 190”。
  - 正确：“Meta 授权已失效，当前只能查看缓存数据。请重新连接。”
- 写操作按钮使用明确动词：
  - “保存草稿”
  - “发布到 Meta”
  - “暂停 12 个广告系列”
- 不使用含糊的“确定”作为唯一操作文案。
